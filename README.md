# Clock Search

**A minimal browser start page with a live age counter and instant search.**

🔗 **Live demo:** https://apoben.github.io/clock-search/

## Features
- Live age counter with configurable decimal precision
- Start typing anywhere to search — input is auto-focused
- Selectable search engine (Google, DuckDuckGo, …)
- Settings saved locally; no tracking, no backend

## Tech Stack
HTML · CSS · Vanilla JavaScript

## Usage
Open the live demo and set it as your browser's home / new-tab page, or serve the folder locally:
```bash
npx serve .
```
